# 氯气与次氯酸

## 氯气的结构与性质

### 结构

氯气（$\ce{Cl2}$）是分子晶体，含有的化学键类型为非极性共价键。

氯元素属于 VIIA 族，故氯原子最外层有七个电子，电子排布式：$\ce{[Ne] 3s^2 3p^5}$。

::: details Q：试比较 $\ce{F2}$，$\ce{Cl2}$，$\ce{Br2}$，$\ce{I2}$ 的沸点高低。
$\ce{F2}$，$\ce{Cl2}$，$\ce{Br2}$，$\ce{I2}$ 都是分子晶体且结构相似，相对分子质量 $\ce{F2} < \ce{Cl2} < \ce{Br2} < \ce{I2}$，分子间作用力 $\ce{F2} < \ce{Cl2} < \ce{Br2} < \ce{I2}$，故沸点 $\ce{F2} < \ce{Cl2} < \ce{Br2} < \ce{I2}$。
:::

### 物理性质

色味态：黄绿色，有刺激性气味气体。

溶解性：$1 : 2$ 溶于水，属于可溶于水的气体；易溶于有机溶剂；难溶于饱和食盐水。

::: details Q：$\ce{Cl2}$ 难溶于饱和食盐水的原因是什么？
$\ce{Cl2 + H2O <=> H+ + Cl- + HClO}$，饱和食盐水中 $\ce{Cl-}$ 浓度高，反应平衡向左移动，故$\ce{Cl2}$ 难溶于饱和食盐水。
:::

其他性质：易液化。

### 化学性质

#### 酸性（广义）

与水反应呈酸性，方程式：$\ce{Cl2 + H2O <=> H+ + Cl- + HClO}$。

$\ce{Cl2}$ 通入石蕊溶液中的现象：**先变红后褪色**（原因见 $\ce{HClO}$ 的性质）。

---

与 $\ce{NaOH}$ 反应，方程式：$\ce{Cl2 + 2NaOH \xlongequal{} NaCl + NaClO + H2O}$

产品称为 $84$ 消毒液，有效成分为 $\ce{NaClO}$。

---

与**石灰乳**（$\ce{Ca(OH)2}$ 的悬浊液）反应，方程式：$\ce{Cl2 + Ca(OH)2 \xlongequal{} CaCl2 + Ca(ClO)2 + H2O}$

产品称为漂白粉，有效成分为 $\ce{Ca(ClO)2}$，主要成分为 $\ce{CaCl2}$、$\ce{Ca(ClO)2}$、$\ce{Ca(OH)2}$；经提纯后称为漂粉精，主要成分为 $\ce{Ca(ClO)2}$。

#### 氧化性

有强氧化性，与活泼和不活泼的金属单质以及氢气反应，**将其氧化到较高价态**：

|   物质    |                  反应方程式                  |                         现象                         |
| :-------: | :------------------------------------------: | :--------------------------------------------------: |
| $\ce{Fe}$ |  $\ce{3Cl2 + 2Fe \xlongequal{点燃} 2FeCl3}$  |    剧烈燃烧，生成**棕褐色**的烟，溶于水呈**黄色**    |
| $\ce{Cu}$ |   $\ce{Cl2 + Cu \xlongequal{点燃} CuCl2}$    |   剧烈燃烧，生成**棕黄色**的烟，溶于水呈**蓝绿色**   |
| $\ce{Na}$ |   $\ce{Cl2 + 2Na \xlongequal{点燃} 2NaCl}$   |        剧烈燃烧，生成**白色**的烟，火焰呈黄色        |
| $\ce{H2}$ | $\ce{Cl2 + H2 \xlongequal{点燃或光照} 2HCl}$ | 光照时爆炸；点燃时安静地燃烧，火焰呈苍白色，生成白雾 |

---

与溶液中物质反应体现氧化性，见[通用氧化性、还原性顺序表](/chemistry/elemental/#%E9%80%9A%E7%94%A8%E6%B0%A7%E5%8C%96%E6%80%A7%E3%80%81%E8%BF%98%E5%8E%9F%E6%80%A7%E9%A1%BA%E5%BA%8F%E8%A1%A8)。

可利用 $\ce{Cl2}$ 与 $\ce{I-}$ 的反应来检验 $\ce{Cl2}$：使用湿润的淀粉-$\ce{KI}$ 试纸，若试纸变蓝，则说明 $\ce{Cl2}$ 存在。

---

溶液中，$\ce{Cl2}$ 还可将 $\ce{I2}$ 氧化为 $\ce{IO3-}$，方程式：$\ce{6H2O + 5Cl2 + I2 \xlongequal{} 2HIO3 + 10HCl}$

---

空气中，$\ce{Cl2}$ 可与 $\ce{NH3}$ 反应。

- 若 $\ce{NH3}$ 为少量，方程式：$\ce{Cl2 + 2NH3 \xlongequal{} N2 + 6HCl}$；
- 若 $\ce{NH3}$ 为过量，$\ce{NH3}$ 与生成的 $\ce{HCl}$ 继续反应，总方程式：$\ce{Cl2 + 8NH3 \xlongequal{} N2 + 6NH4Cl}$

#### 其他性质

$\ce{Cl2}$ 在热的碱溶液中可发生歧化反应，生成氯离子和氯酸根，方程式：$\ce{3Cl2 + 6OH- \xlongequal{\Delta} 5Cl- + ClO3- + H2O}$

$\ce{Cl2}$ 无漂白性，有漂白性的是 $\ce{HClO}$。

## 次氯酸的性质

### 物理性质

色味态：无色至黄绿色（混有 $\ce{Cl2}$），通常在水溶液中存在（故无法描述味）。

溶解性：溶于水。

### 化学性质

#### 酸性

次氯酸属于在水中电离呈酸性：$\ce{HClO <=> H+ + ClO-}$。可以与碱反应。

次氯酸可以与更弱的酸发生强酸制弱酸。

例如，已知酸性 $\ce{H2CO3} > \ce{HClO} > \ce{HCO3-}$，则由水解平衡的知识可知其共轭碱碱性 $\ce{HCO3-} < \ce{ClO-} < \ce{CO3^2-}$。故可以发生 N 型转换的反应：$\ce{HClO + CO3^2- \xlongequal{} ClO- + HCO3-}$。

#### 强氧化性

$\ce{HClO}$ 中的氯元素为 $+1$ 价，具有强氧化性。其还原产物多数情况下为 $\ce{Cl-}$。

#### 其他性质

漂白性：$\ce{HClO}$ 具有强氧化性，可以将有色物质氧化为无色物质，故具有漂白性，**且这种漂白不可逆**。

不稳定性：$\ce{HClO}$ 受热歧化，生成氯酸和盐酸：$\ce{3HClO \xlongequal{\Delta} 2HCl + HClO3}$；见光会分解为盐酸和氧气：$\ce{2HClO \xlongequal{光} 2HCl + O2 ^}$。

::: details Q：试列出新制氯水和久制氯水中含有的微粒。

- 新制氯水：$\ce{Cl2}$、$\ce{HClO}$、$\ce{H2O}$、$\ce{H+}$、$\ce{Cl-}$、$\ce{OH-}$（水电离产生）、$\ce{ClO-}$。
- 久制氯水：$\ce{H+}$、$\ce{Cl-}$、$\ce{OH-}$、$\ce{H2O}$。叠加 $\ce{2HClO \xlongequal{光} 2HCl + O2 ^}$ 与 $\ce{Cl2 + H2O <=> HCl + HClO}$，平衡向左移动。

:::

## 次氯酸盐的性质

### 物理性质

色味态：$\ce{NaClO}$ 溶液为浅黄色液体。

溶解性：溶于水。

### 化学性质

#### 碱性

次氯酸根水解呈碱性：$\ce{ClO- + H2O <=> HClO + OH-}$。

依旧可以强制弱，这也是漂粉精和 $84$ 消毒液的漂白原理：

已知酸性 $\ce{H2CO3} > \ce{HClO} > \ce{HCO3-}$，同上有碱性 $\ce{HCO3-} < \ce{ClO-} < \ce{CO3^2-}$

$84$ 消毒液：$\ce{NaClO + H2O + CO2 \xlongequal{} NaHCO3 + HClO}$。

漂粉精：$\ce{Ca(ClO)2 + H2O + CO2 \xlongequal{} CaCO3 + 2HClO}$。

::: details Q：为何 $84$ 消毒液在空气中反应生成碳酸氢钠，而漂粉精生成碳酸钙？
考虑碳酸的两极电离：

$$
\begin{aligned}
  \ce{H2CO3 <=> H+ + HCO3-},\ &K_{a1} \approx 4.3 \times 10^{-7} \\
  \ce{HCO3- <=> H+ + CO3^2-},\ &K_{a2} \approx 4.7 \times 10^{-11}
\end{aligned}
$$

而次氯酸是弱酸，在溶液中倾向于以分子形式存在，故次氯酸根抢氢离子的能力比较强，有：

$$
\ce{ClO- + H+ \xlongequal{} HClO}, K = \frac{1}{K_a} \approx 3.0 \times 10^7
$$

于是我们可以计算出 $84$ 消毒液中反应的平衡常数，叠加方程式 $1$ 与 $3$：

$$
\ce{ClO- + H2O + CO2 \xlongequal{} HCO3- + HClO}, K = \frac{K_{a1}}{K_a} \approx 12.9
$$

而在 $84$ 消毒液中，若再叠加方程式 $2$，容易发现 $K$ 极小，故几乎不生成碳酸钠。

---

而对于漂粉精，其中的钙离子遇碳酸根会沉淀

$$
\ce{Ca^2+ + CO3^2- \xlongequal{} CaCO3 v}, K = \frac{1}{K_{sp}} \approx 3.0 \times 10^8
$$

叠加反应为 $\ce{Ca(ClO)2 + H2O + CO2 \xlongequal{} CaCO3 v + 2HClO}$，可以计算其 $K$ 值：

$$
K = \frac{K_{a1} K_{a2}}{K_{sp} K_a^2} \approx 5.46 \times 10^6 \gg 12.9
$$

因此该反应占主导地位。
:::

#### 氧化性

同上，次氯酸根的还原产物多数情况下为 $\ce{Cl-}$，有时为氯气，如 $84$ 消毒液与盐酸（老式洁厕灵中的成分）反应：$\ce{NaClO + 2HCl \xlongequal{} Cl2 ^ + NaCl + H2O}$。

#### 其他性质

不稳定性：$\ce{ClO-}$ 受热歧化，生成氯酸根和氯离子：$\ce{3ClO- \xlongequal{\Delta} ClO3- + 2Cl-}$。故制备次氯酸盐需要冰水浴，避免发生该副反应。

次氯酸盐固体也可能受热或见光分解，释放氧气，如 $\ce{2NaClO \xlongequal{光或热} 2NaCl + O2 ^}$。

## 氯气的制备

### 实验室制备

1774 年，德国化学家 Scheele 在实验室中用软锰矿（$\ce{MnO2}$）与**浓盐酸**加热，反应制得了氯气，这也是教材中提到的实验室制备氯气的主要方法，反应方程式为：

$$
\ce{MnO2 + 4HCl(浓) \xlongequal{\Delta} MnCl2 + Cl2 ^ + 2H2O}
$$

注意：该反应需要浓盐酸（体现更强的还原性），而随着反应进行盐酸浓度会降低，反应会停止，这点经常需要纳入考虑。盐酸在此反应中体现酸性和还原性。

该反应可以通过如下装置进行：

<Figure src="/images/chemistry/elemental/scheele-Cl2.png" description="Scheele 实验室制备氯气的装置"/>

其中饱和食盐水除去氯气中的氯化氢，浓硫酸去除水分，集气瓶排空气法吸收气体，最后氢氧化钠溶液进行尾气处理。

除此之外，还有几种常见的实验室制备氯气的方法，这些方法没有特殊的反应条件：

1. 用氯酸钾和浓盐酸，发生归中反应生成氯气；
2. 用次氯酸钠和浓盐酸，发生归中反应生成氯气；
3. 用高锰酸钾和浓盐酸，发生一般的氧化还原反应生成氯气。

::: details Q：试写出上述反应的化学方程式。

1. $\ce{KClO3 + 6HCl(浓) \xlongequal{} 3Cl2 ^ + 3H2O + KCl}$；
2. $\ce{NaClO + 2HCl(浓) \xlongequal{} Cl2 ^ + H2O + NaCl}$；
3. $\ce{2KMnO4 + 16HCl(浓) \xlongequal{} 2MnCl2 + 5Cl2 ^ + 2KCl + 8H2O}$。

:::

### 工业制备

工业上使用电解饱和食盐水的方法生产 $\ce{NaOH}$ 和 $\ce{Cl2}$，并得到副产物 $\ce{H2}$，这样的工业叫做氯碱工业。

从源头追溯该工业，第一步是海水晒盐，得到粗盐；第二步是粗盐提纯；第三步是电解饱和食盐水，在一种叫电解池的工业装置中发生，下面详细介绍这一步工序。

<Figure src="/images/chemistry/elemental/electrolytic-cell-simplified.png" description="电解池的简化模型"/>

电解池由直流电源、阳极、阴极、电解质和电解槽组成。与电源正极相连的电极称为阳极，与电源负极相连的电极称为阴极。由电路知识可知，电子从电源负极流出，经外电路到达电解池的阴极；阳极上需要得电子，经外电路流回电源正极。

电解池可以氧化还原反应拆分为两个**半反应**：在阳极，物质失去电子，发生氧化反应；在阴极，物质得到电子，发生还原反应。这样既能将氧化产物和还原产物分开，又能借助外加电能推动原本非自发的反应进行。这两个**半反应**都称为**电极反应**。注意，**电极反应不写气体或沉淀符号**。

考虑饱和食盐水中的微粒：主要有 $\ce{Na+}$、$\ce{Cl-}$，还有水分子电离产生的微量 $\ce{H+}$、$\ce{OH-}$。

在阳极，我们需要物质失电子。溶液中氯离子浓度较高，故阳极上氯离子失电子变为氯气，阳极反应为 $\ce{2Cl- - 2e- \xlongequal{} Cl2}$。

在阴极，我们使物质得电子。水溶液中，外加电流很难使 $\ce{Na+}$ 得电子变为 $\ce{Na}$。但水分子电离产生的 $\ce{H+}$ 可以得电子变为氢气。叠加 $\ce{H2O <=> H+ + OH-}$ 与 $\ce{2H+ + 2e- = H2}$，可得出阴极反应为 $\ce{2H2O + 2e- \xlongequal{} H2 + 2OH-}$。

阳极不能用铁、锌等较活泼的金属，因为这些金属本身更容易失电子，反应会发生在金属上而不是氯离子上。可使用铂或石墨等惰性电极。阴极可以使用铁等金属电极。

|   电极   |                阳极                 |                   阴极                    |
| :------: | :---------------------------------: | :---------------------------------------: |
| 电极材料 |                石墨                 |                 石墨或铁                  |
| 电极反应 | $\ce{2Cl- - 2e- \xlongequal{} Cl2}$ | $\ce{2H2O + 2e- \xlongequal{} H2 + 2OH-}$ |
| 电极产物 |             $\ce{Cl2}$              |          $\ce{H2}$、$\ce{NaOH}$           |
| 产物检验 |     湿润的淀粉 - 碘化钾试纸变蓝     |            爆鸣实验，酚酞变红             |
| 产物用途 |       化工原料、自来水消毒等        |            化工原料、合成氨等             |

由电流的定义（正电荷运动的方向），我们知道在这个反应中电流的方向是正极 $\to$ 阳极 $\to$ 溶液 $\to$ 阴极 $\to$ 负极，而电子的运动是负极 $\to$ 阴极，阳极 $\to$ 正极，注意：**溶液中没有电子，由离子运动来传递电流**。

溶液中，$\ce{Cl-}$ 主要往阳极运动；而阴极上，水分子电离产生的 $\ce{OH-}$ 迁移速率慢，从而堆积，使得阴极附近溶液呈碱性，且吸引迁移速率更快的 $\ce{Na+}$。

---

然而，仍有少量 $\ce{Cl-}$ 迁移到阴极附近，使得产出的 $\ce{NaOH}$ 溶液中混有少量 $\ce{NaCl}$。但阴极反应并不需要 $\ce{Cl-}$。故工业上使用**离子交换膜**，使得自由 $\ce{Na+}$ 能够迁移到阴极附近，而 $\ce{Cl-}$ 不能迁移到阴极附近，从而得到纯净的 $\ce{NaOH}$ 溶液；来自阴极的 $\ce{OH-}$ 也不能迁移到阳极附近与 $\ce{Cl2}$ 反应，从而使 $\ce{Cl2}$ 产率更高。
