# 高中化学概述

高中化学主要分为以下五个板块：

- 理论化学
- 元素化学
- 化学实验
- 有机化学
- 结构化学

其中，理论化学和元素化学是考的最多的两个部分。但是理论化学的学习中有许多元素化学的例子，元素化学中也有很多要应用理论化学的地方，~~形成了自环，不是 DAG~~。

所以为了解决这个先后顺序的冲突可以把理论化学拆成两部分来学习，先学习一部分基础的理论化学，在学习完元素化学之后补全更深的理论化学。可以分成以下的六个板块进行学习。

1. [化学基本原理](/chemistry/basic-principles/)
2. [元素化学](/chemistry/elemental/)
3. 化学原理
4. 高中结构化学
5. 化学实验
6. 有机化学

那么话不多说，就让我们踏进高中化学的大门吧！
