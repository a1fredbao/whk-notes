## 贡献

若要做出贡献，请 fork 本仓库，修改后提交 PR。

本地预览，请先使用 bun 命令安装依赖并启动开发服务器：

```bash
bun install
bun run docs:dev
```

构建与预览：

```bash
bun run docs:build
bun run docs:preview
```
